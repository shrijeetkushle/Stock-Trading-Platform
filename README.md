# Stock Trading Platform 📈

A full-stack stock trading platform inspired by modern brokerage applications, providing users with a dashboard to manage holdings, positions, watchlists, and stock-market data.

## 🚀 Features

* 🔐 User authentication
* 📊 Trading dashboard
* 📈 Stock charts and market data
* 💼 Holdings management
* 📋 Positions tracking
* ⭐ Watchlist
* 🔄 REST APIs
* 🗄️ MongoDB database
* 🌐 Separate frontend and backend architecture

## 🛠️ Tech Stack

**Frontend**

* React.js

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

**Other**

* REST APIs
* AWS

## 📂 Project Structure

```text
Stock-Trading-Platform/
```

## 📌 Project Overview

The application provides a web-based interface for viewing market information and managing stock-related data. The backend provides REST APIs and handles data persistence using MongoDB.
